# 3D-Модели наград и знаков отличия (GLB)

Поместите сюда 3D-модели медалей и нагрудных знаков в формате `.glb`:

### Ожидаемые имена файлов:
1. `medal_otvaga.glb` — **Медаль «За отвагу»** (СССР, главная солдатская награда)
2. `medal_afghan_people.glb` — **Медаль «Воину-интернационалисту от благодарного афганского народа»**
3. `badge_gvardia.glb` — **Нагрудный знак «Гвардия»**
4. `badge_paratrooper.glb` — **Знак «Парашютист-отличник»**
5. `badge_internationalist.glb` — **Нагрудный знак «Воину-интернационалисту»**
6. `medal_anniversary.glb` — **Юбилейные медали вывода войск** (10, 20, 25, 30 лет)

### Как работает система:
- Если реальный файл `.glb` ещё не загружен, приложение автоматически отображает высококачественную процедурную 3D-модель медали с колодкой, лентой и эмалью (Mock).
- Как только вы положите файл `.glb` с указанным именем в эту папку, система автоматически подхватит его и отобразит вместо заглушки!

### Рекомендации:
- Формат: `.glb` (glTF binary)
- Размер файла: до 5–10 МБ на модель
- Оптимизация текстур и сжатие геометрии: [gltf.report](https://gltf.report/)
