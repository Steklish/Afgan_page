# 3D-Модели фотоаппаратуры военкора (GLB)

Поместите сюда 3D-модели фотоаппаратов Алексея Козлова в формате `.glb`:

### Ожидаемые имена файлов:
1. `camera_fed2.glb` — **Фотоаппарат ФЭД-2** («Феликс Эдмундович Дзержинский» — легендарный дальномерный металлический фотоаппарат, прошедший все боевые операции в Афганистане)
2. `camera_zenit.glb` — **Фотоаппарат «Зенит»** (зеркальный фотоаппарат для цветных слайдов ORWO/Свема)
3. `camera_smena8m.glb` — **Фотоаппарат «Смена-8М»** (учебный центр ВДВ в Фергане)
4. `photo_enlarger_leningrad.glb` — **Фотоувеличитель «Ленинград-4»** (палаточная фотолаборатория десантников)

### Как работает система:
- До загрузки реального `.glb` файла в 3D-сцене отображается процедурная модель винтажного советского фотоаппарата (металлический корпус, дальномер, тубус объектива Индустар-26М, диск выдержек, спусковая кнопка).
- При наличии файла `.glb` в этой папке сцена отобразит загруженную 3D-модель с интерактивными хотспотами деталей аппарата.

### Рекомендации:
- Формат: `.glb` (glTF binary)
- Размер: до 10–15 МБ
- Оптимизация: [gltf.report](https://gltf.report/)
