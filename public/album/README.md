# Альбом «Афганский репортаж» (Алексей Козлов)

В этой папке хранятся фотографии и метаданные фронтового фоторепортажа.

## Как заменить или добавить фотографии:

1. **Фотографии (`photos/`):**
   Поместите ваши файлы изображений (JPG, PNG, WEBP) в каталог `public/album/photos/`.
   Рекомендуется использовать понятные имена файлов без пробелов: `photo_01.jpg`, `photo_02.jpg` и т.д.

2. **Описания (`album.json`):**
   Откройте файл `public/album/album.json` и добавьте или измените записи:
   ```json
   {
     "id": 1,
     "title": "Название фотографии",
     "year": "1985",
     "location": "Место съемки (провинция / застава)",
     "description": "Исторический комментарий, воспоминания или архивные сведения",
     "src": "./album/photos/ваше_фото.jpg"
   }
   ```
   Галерея автоматически обновится и отобразит новые снимки с зумом и описаниями.
