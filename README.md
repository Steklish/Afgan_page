# Интерактивный 3D-плакат памяти «У каждого времени свои герои»

Шаблон веб-плаката для конкурса в соответствии с положением (п. 5.3–5.5).

## 🚀 Быстрый запуск и локальное тестирование

### 1. Установка зависимостей (уже выполнена в проекте)
```bash
npm install
```

### 2. Запуск локального сервера разработки (Hot-Reload)
```bash
npm run dev
```
После запуска откройте в браузере адрес, указанный в терминале (обычно `http://localhost:5173/`).

### 3. Проверка production-сборки (эмуляция GitHub Pages)
```bash
npm run build
npm run preview
```
Откройте `http://localhost:4173/` и проверьте консоль разработчика (`F12`), чтобы убедиться в отсутствии ошибок 404.

## 📂 Структура медиафайлов (`public/`)

Разместите материалы в соответствующие папки внутри каталога `public/`:

- `public/models/scene.glb` — Ваша оптимизированная 3D-модель (до 15–20 МБ, текстуры до 2K, рекомендуется сжатие через [gltf.report](https://gltf.report/)).
- `public/audio/voice_archive.mp3` — Аудиозапись воспоминаний, интервью или стихов.
- `public/video/documentary.mp4` — Видеоролик кинохроники (или YouTube embed в `src/App.tsx`).
- `public/images/hero_photo.png` — Архивный портрет героя.
- `public/images/poster_preview.png` — Статичный скриншот постера для отчёта жюри и превью.

> **💡 Подсказка:** Пока реальный файл `scene.glb` не добавлен, в приложении работает интерактивная мемориальная 3D-стела с 4 хотспотами. Переключаться между демо-стелой и моделью `scene.glb` можно в один клик по кнопке в левом верхнем углу интерфейса.

## 🌐 Деплой на GitHub Pages

В репозитории уже настроен рабочий процесс GitHub Actions: `.github/workflows/deploy.yml`.

### Пошаговые действия:

1. Создайте репозиторий на [GitHub](https://github.com/new).
2. Привяжите локальный репозиторий и отправьте код:
   ```bash
   git add .
   git commit -m "Интерактивный 3D плакат памяти"
   git remote add origin https://github.com/<ВАШ_АККАУНТ>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   git push -u origin main
   ```
3. В настройках репозитория на GitHub:
   - Откройте **Settings** → **Pages**.
   - В поле **Source** выберите: **GitHub Actions**.
4. Дождитесь завершения сборки во вкладке **Actions** (зеленая галочка).
5. Ваш сайт будет доступен по адресу:
   `https://<ВАШ_АККАУНТ>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/`
